# Простая физика

Интерактивное веб-приложение для изучения физики. Откройте `index.html` в любом браузере — установка не нужна.

## Разделы
- **Бросок под углом** — траектория, время полёта, дальность и высота; можно сменить планету (g).
- **Маятник** — численное моделирование, сравнение реального периода с формулой T = 2π√(L/g).
- **Пружина** — гармонические колебания, график x(t) и переход энергии Eк ↔ Eп.
- **Столкновения** — упругий и неупругий удар, сохранение импульса и потери энергии.
- **Формулы и калькулятор** — справочник основных формул школьного курса с расчётом.
